# OurShopping

В настройках покупок доступны вкладки «Продукты» и «Магазины».
Магазины общие для участников пространства: можно создать магазин, изменить
название и выбрать эмодзи или загрузить свою иконку. Магазин указывается при
добавлении покупки или в окне «Цена и магазин» в режиме редактирования.
В обычном списке отображаются цена и магазин. Фильтр позволяет выбрать магазин,
а порядок «По магазинам» разбивает покупки на группы с отдельными количествами.

Для установки на новую базу после основной схемы выполните `shopping-stores.sql`.
Он добавляет магазины, привязку покупок, права участников и синхронизацию Realtime.
Магазины также сохраняются в локальной копии списка для просмотра без интернета.
